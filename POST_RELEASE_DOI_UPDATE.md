# Post-release DOI metadata update

The immutable `v1.0.0` Git tag/release should remain unchanged.

After Zenodo minted DOI `10.5281/zenodo.22120243`, update the GitHub **main branch only** with the accompanying metadata files:

- `README.md` — DOI badge/link and archival citation
- `CITATION.cff` — `doi` and `url`
- `RELEASE_DOI_RECORD.md` — final version DOI and GitHub release
- `ZENODO_METADATA_v1.0.0.md` — final DOI record

These are post-release metadata edits; they do not change scientific code or the already archived Zenodo object.
